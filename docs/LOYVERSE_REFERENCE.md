# Referencia funcional de Loyverse

Objetivo: conservar las posiciones y los recorridos del Back Office y POS de Loyverse en la medida en que se puedan verificar, utilizando una identidad visual original.

## Fuente oficial comprobada

- [Crear artículos desde Back Office](https://help.loyverse.com/es/help/how-add-items-loyverse-back-office): **Lista de artículos** → **Agregar artículo** → formulario → **Guardar**.
- [Artículos y categorías en POS](https://help.loyverse.com/es/help/items-categories): menú superior izquierdo → Artículos → agregar en esquina inferior derecha.
